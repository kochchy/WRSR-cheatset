[h1]Cheatset Plugin[/h1]
A plugin for [b]TesmioLoader[/b] that automatically enables the game's internal cheat menu and its features on every map load, saving you from manually pressing C+H+E and clicking the checkboxes every time.

[h2]Features[/h2]
[list]
[*] [b]Auto-Activation[/b]: Automatically writes directly into the game's memory to enable the cheat menu features instantly when the world loads.
[*] [b]Fully Configurable[/b]: Every cheat function can be toggled on or off in the INI file.
[*] [b]Available Toggles[/b]: Speed up construction, Speed up research, Speed up vehicle production, Speed up growing trees, Speed up pollution, Speed up wear and tear, Experimental traffic pathfinding, and Train route signal.
[*] [b]Native Integration[/b]: Uses exact memory offsets to seamlessly switch features on without brittle UI macros.
[/list]

[h2]Installation[/h2]
[b]Important:[/b] This mod requires [url=https://github.com/Tesmio/TesmioLoader]TesmioLoader[/url] to work! Subscribing to this workshop item will download the files to your workshop folder, but you must manually install the plugin.
[list=1]
[*] Ensure you have the TesmioLoader framework installed.
[*] Locate the downloaded files in your Steam workshop directory (usually [code]Steam\steamapps\workshop\content\784150\...\)[/code]
[*] Copy [code]cheat_set.dll[/code] and [code]cheat_set.ini[/code] to your game directory: [code]Steam\steamapps\common\SovietRepublic\tesmioloader\build\plugins\[/code]
[*] Activate the plugin via the [code]tesmiolauncher.exe[/code] interface.
[/list]

[h2]Configuration[/h2]
Edit [code]cheat_set.ini[/code] in your plugins folder to adjust which cheat functions you want automatically enabled. The file is fully commented in English.
