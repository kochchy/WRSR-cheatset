[h1]Cheatset Plugin[/h1]
A plugin for [b]TesmioLoader[/b] that automatically enables the game's internal cheat menu and your selected cheat functions on every map load, saving you from manually pressing C+H+E and clicking individual checkboxes every time.

[h2]Features[/h2]
[list]
[*] [b]Direct Memory Activation[/b]: Directly configures the game's internal world structures instantly upon map load.
[*] [b]Full Granular Control[/b]: Every single toggle in the cheat menu can be individually set to 0 (disabled) or 1 (enabled) via the INI file.
[*] [b]All 10 General Cheat Functions Supported[/b]:
  [list]
  [*] Speed up construction
  [*] Speed up research
  [*] Speed up vehicle production
  [*] Speed up growing trees
  [*] Speed up pollution
  [*] Speed up wear and tear
  [*] Landscape editor mode
  [*] Experimental traffic pathfinding
  [*] CO cooperate
  [*] Train route signal
  [/list]
[*] [b]Vanilla Default Out-of-the-Box[/b]: Clean defaults matching standard game loading behavior (CO cooperate & Train route signal enabled, all accelerators disabled until you turn them on).
[/list]

[h2]Installation[/h2]
[b]Important:[/b] This mod requires [url=https://github.com/Tesmio/TesmioLoader]TesmioLoader[/url] to work! Subscribing to this workshop item will download the files to your workshop folder, but you must manually install the plugin.
[list=1]
[*] Ensure you have the TesmioLoader framework installed.
[*] Locate the downloaded files in your Steam workshop directory (usually [code]Steam\steamapps\workshop\content\784150\...\)[/code]
[*] Copy [code]cheat_set.dll[/code] and [code]cheat_set.ini[/code] to your game directory: [code]Steam\steamapps\common\SovietRepublic\tesmioloader\build\plugins\[/code]
[*] Activate the plugin via the [code]tesmiolauncher.exe[/code] interface.
[/list]

[h2]Configuration[/h2]
Edit [code]cheat_set.ini[/code] in your plugins folder to customize which cheat features activate automatically on load.
